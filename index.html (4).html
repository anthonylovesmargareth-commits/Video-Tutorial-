How to Embed a Video

A simple step-by-step guide to adding videos to a website.

Step 1: Find a Video

First, open YouTube and find a video that you want to add to your website. Make sure the video is appropriate and allows embedding.

Step 2: Open the Video

Click on the video to open its individual YouTube page. This will give you access to the sharing options.

Step 3: Click the Share Button

Underneath the video, find and click the Share button. This opens a menu with different ways to share the video.

Step 4: Select Embed

In the sharing menu, select the Embed option. This allows you to get the HTML code needed to display the video on another website.

Step 5: Copy the Embed Code

YouTube will display an iframe code. Click Copy to copy the entire code to your clipboard.

Step 6: Add the Code to Your Website

Open your HTML file in a code editor. Paste the iframe code inside the body section wherever you want the video to appear.

Step 7: Save and Test

Save your HTML file and open the webpage in a browser. Check that the video appears correctly and can be played.
